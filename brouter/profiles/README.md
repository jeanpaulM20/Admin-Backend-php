# Zusatzprofile

`hiking-beta.brf` — Wanderprofil, das das Backend für „wandern" und „joggen"
nutzt. Es ist kein Bestandteil des offiziellen BRouter-Releases, sondern
stammt aus der Profilsammlung von poutnik (siehe Kopfzeile der Datei) und
wird auf brouter.de bereitgestellt. Kopie vom 3. Oktober 2026
(`https://brouter.de/brouter/profiles2/hiking-beta.brf`).

Alle anderen vom Backend verwendeten Profile (`trekking`, `fastbike`,
`gravel`, `mtb`, `hiking-mountain`) liegen im Release unter `profiles2/`.
