## Implementation Notes

### File Naming Convention
Use the exercise name normalized to lowercase kebab-case:
- `kettlebell-swing-russian.png`
- `pistol-squat.png`
- `box-jump-beidbeinig.png`

### Recommended Image Size
- **Generation**: 1024×1024 (DALL-E 3 native)
- **App Icon**: 80×80 dp (exported as 160×160 px for 2x density)
- **Format**: PNG with transparent background (remove white in post-processing)

### Post-Processing Pipeline
1. Generate at 1024×1024
2. Remove white background → transparent PNG
3. Invert to white lines on transparent (for dark UI theme)
4. Resize to 160×160 px
5. Optimize with `pngquant` or similar

### Flutter Integration
```dart
// In exercise catalog, replace the number badge with:
CircleAvatar(
  radius: 22,
  backgroundColor: AppColors.surface2,
  child: Image.asset(
    'assets/exercise-icons/${exercise.iconSlug}.png',
    width: 32, height: 32,
    color: AppColors.text, // tint for theme
    errorBuilder: (_, __, ___) => Icon(
      _groupIcon(exercise.group), // fallback to category icon
      color: AppColors.muted, size: 20,
    ),
  ),
)
```
